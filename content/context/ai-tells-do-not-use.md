# AI-tells y muletillas baneadas (que delatan contenido generado por modelo)

Lectura obligatoria para todos los agentes escritores: `blog-writer`, `blog-renter`, `linkedin-carlos`, `linkedin-juan`, `linkedin-company`, `press-release`, `reddit-changelog`, `community-engager`. Y obligatorio para `editor-qa` como criterio de revisión adicional.

**Regla cero:** si dudás si una frase es muletilla, no la uses. Hay 10 maneras de decir lo mismo de forma humana; pickeá una.

## Verbos infladores (cero tolerancia)

- delve into, dive into, dive deep, embark on a journey
- leverage (como verbo), leveraging
- unlock (potential / value / growth), unlocking
- empower, empowering, empowerment
- elevate (your X), take it to the next level
- transform / transformative (cuando no es literal)
- revolutionize, revolutionary, game-changer, game-changing
- streamline, streamlined
- seamless, seamlessly, frictionless
- robust (describiendo software)
- cutting-edge, state-of-the-art, best-in-class, world-class, next-generation
- foster (relationships, growth)
- showcase, showcasing
- spearhead, spearheading
- usher in (a new era)
- pave the way
- bridge the gap
- move the needle
- hit the ground running
- bring to the table

## Regla de tres abusada

- Tres adjetivos pegados: "fast, easy, and reliable" / "powerful, intuitive, and scalable"
- Tres beneficios en lista: "save time, save money, and grow your business"
- Usar máximo una serie de tres por pieza, y solo si los tres aportan algo distinto.

## Puntuación y formato delator

- Em-dashes (—): YA prohibidos en todo el sistema.
- Comillas para énfasis en palabras normales ("incredible", "amazing"): elimine.
- Excesivos dos puntos en headers de listas.
- Triple-line-break poético en LinkedIn (cada frase su propio párrafo): bandera roja salvo que la pausa lo justifique.
- 1️⃣ 2️⃣ 3️⃣ emoji-bullets en LinkedIn: prohibidos.
- 👇 flecha de "leé más abajo": prohibida.

## "Naturalizar" mal hecho (también son tells)

- Empezar una oración con minúscula a propósito ("just my two cents...")
- "ngl" / "tbh" / "imho" mezclado con copy formal
- "Real talk:" prefix
- Hook + "(read till the end)" o "(spoiler at the end)"
- Frases iniciando con "Look," como falsa franqueza

## Específicas del rubro PropTech / leasing

- "Future of leasing" / "future of property management" (cuando no hay claim concreto del futuro)
- "Revolutionizing the rental experience"
- "Empowering landlords" / "empowering property managers"
- "Smart leasing" (cuando no se aclara qué hace inteligente)
- "Reimagining tenant experience"
- "Leasing for the modern operator"

## Reemplazos humanos que sí funcionan

| Muletilla | Reemplazo más humano |
|---|---|
| leverage X | use X, lean on X, run X |
| unlock value | get more out of X, find the X that was sitting there |
| seamless integration | the integration just works / X talks to Y directly |
| streamline | cut the manual step, take out the handoff |
| empower the team | give the team back the hour / let the team focus on Y |
| transform your X | change how X works for you |
| in today's fast-paced world | this year / right now / in 2026 (sé específico) |
| robust | handles the load / does not break under X |
| best-in-class | the one we ship / what we built |
| It's important to note | (often delete entirely) |
| furthermore | and, also, plus |
| in conclusion | (often delete the whole paragraph) |

## Checklist final (aplicar antes de cerrar cualquier borrador)

- [ ] ¿Hay una frase que podría aparecer en CUALQUIER landing page de SaaS? Reescribir.
- [ ] ¿Tres adjetivos consecutivos? Tirar dos.
- [ ] ¿Abre con "Excited / Thrilled / Picture this / Imagine / In today's"? Reescribir el hook.
- [ ] ¿Cierre con "I hope this helps" o equivalente? Borrar.
- [ ] ¿Algún uso de "delve", "leverage" (verbo), "unlock", "elevate", "streamline", "seamless", "robust", "transform", "game-changer", "revolutionize", "empower", "showcase"? Reescribir.
- [ ] ¿Algún "It's not just X, it's Y"? Reescribir.
- [ ] ¿Numbers + source attribution preservados y específicos?
- [ ] ¿Las frases podrían venir de una conversación real entre dos operadores? Si no, reescribir.
