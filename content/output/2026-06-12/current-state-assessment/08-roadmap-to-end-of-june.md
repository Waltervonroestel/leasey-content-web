## 8.4 Update mechanics

Every weekly pull lives in a new dated folder:

- `output/2026-06-12/current-state-assessment/` (today, preliminary)
- `output/2026-06-19/current-state-assessment/` (week 2 deltas)
- `output/2026-06-26/current-state-assessment/` (week 3 final)

The numbered files match across folders so the founders can diff between sessions. GSC data in `data/` is repulled automatically each Monday at 10:00 UTC by a GitHub Action.
